# pds-design-patterns

Projeto dedicado a estudos em Padrões de Projeto (Design Patterns) em Java para a disciplina de Projeto Detalhado de Software (2026.2).

---

## Compilar e Executar

### Padrão Visitor

**1. Compilar o código:**

```bash
javac visitor/*.java
```

**2. Executar o código:**

```bash
java visitor.Main
```
